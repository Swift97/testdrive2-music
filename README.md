# Test Drive 2 / Grand Prix Circuit music reverse engineering project

_Inside this Github project folder, you will find the results of my research since the beginning of this reverse-engineering project in 2017. This is a small hobby project that I came back to after 9 years of hiatus, done out of love for these games I grew up with. Given this, possible updates to this page might be slow to come. I am publishing this only to spread and archive this knowledge._

### The written information held within this project is effective >SOLELY< for the MS-DOS version of  Test Drive 2 and Grand Prix Circuit.
#### I have no experience with any of their ports or their formats, and all the testing and experimenting were done through the aforementioned version running through DOSBox.

---

# Table of Contents:

### [`SONGS.md`](SONGS.md) - Documentation for `SONGS.BIN`/`MUSIC.BIN`.
* Music tracker format containing every track, their sequencer arrangement, and pattern data.
* This is also where the whole project began :)

### [`VOICES.md`](VOICES.md) - Documentation on `VOICES.BIN`.
* This file is where the game stores definitions of various PC speaker "instruments". It allows for simple effects like staccato, arpeggiation and vibrato.
